  • ❌ Este aplicativo NÃO substitui acompanhamento médico profissional
  • ❌ Este aplicativo NÃO é um dispositivo médico

Recomendação Médica: Se você está tentando parar de fumar, consulte um médico ou profissional de saúde qualificado para obter orientação adequada, especialmente se você tem condições médicas pré-existentes, usa medicamentos, está grávida ou amamentando.

Este aplicativo é apenas um complemento motivacional e não deve ser usado como única ferramenta para parar de fumar.

1. Introdução

O aplicativo "Desafio do Cigarro" é uma ferramenta de gamificação e motivação desenvolvida para apoiar pessoas que desejam parar de fumar. Esta política de privacidade descreve como coletamos, usamos e protegemos suas informações pessoais.

2. Dados Coletados

2.1 Dados Fornecidos pelo Usuário

Coletamos as seguintes informações que você fornece voluntariamente:

  • Nome: usado apenas para personalização da experiência do usuário
  • Idade: coletada diretamente por você e usada exclusivamente para cálculos de gamificação e estatísticas
  • Sexo: usado apenas para personalização da interface
  • Anos fumante: usado para cálculos de progresso e estatísticas
  • Quantidade de cigarros por dia: usado para cálculos de economia financeira e tempo de vida ganho
  • Valor do maço: usado para cálculo de dinheiro economizado
  • Foto de perfil (opcional): você pode adicionar uma foto usando a câmera ou a galeria. Armazenada no Firebase Storage e visível para outros usuários da comunidade
  • E-mail e senha: usados para autenticação segura via Firebase Authentication

2.2 Dados de Uso e Comunidade

Dados de progresso (armazenados localmente e no Firebase): tempo de início do desafio, progresso (tempo sem fumar), estatísticas de uso, datas de interrupção do tabagismo, metas alcançadas, níveis, XP e conquistas.

Dados de comunidade (armazenados no Firebase): mensagens do chat global, mensagens privadas, pedidos de ajuda (SOS), status de presença (online/offline), perfil público (nome, foto, nível e conquistas).

2.3 Dados de Notificações

  • Token de notificação (FCM): usado para enviar notificações push sobre mensagens, pedidos de ajuda e lembretes motivacionais
  • Preferências de notificação: configurações sobre quais tipos de notificações você deseja receber

2.4 O Que NÃO Coletamos

Este aplicativo NÃO coleta informações médicas ou de saúde, tais como:

  • ❌ Dados de saúde física ou mental
  • ❌ Informações sobre condições médicas
  • ❌ Dados de exames médicos
  • ❌ Informações sobre medicamentos ou tratamentos
  • ❌ Dados de prontuários médicos
  • ❌ Qualquer informação que possa ser considerada um registro médico
  • ❌ Localização geográfica
  • ❌ Contatos do seu dispositivo
  • ❌ Outros arquivos ou fotos além da foto de perfil que você escolher

Os dados sobre "progresso", "evolução" e "metas alcançadas" referem-se exclusivamente a dados de gamificação (tempo sem fumar, economia financeira, fases completadas) e NÃO representam avaliações médicas. Os cálculos de "tempo de vida ganho" são estimativas baseadas em fórmulas de gamificação e NÃO são diagnósticos ou avaliações médicas.

3. Como Usamos Seus Dados

3.1 Finalidade do Uso

Todos os dados coletados são usados exclusivamente para: gamificação (personalizar a experiência do desafio de 60 dias), cálculos (dinheiro economizado, tempo de vida ganho, progresso), motivação (estatísticas e gráficos), funcionalidades do app, notificações, comunidade (chat global e mensagens privadas), sistema SOS e exibição de perfil/conquistas.

Importante: os dados são usados apenas para gamificação e motivação pessoal. NÃO são usados para diagnóstico, tratamento ou avaliação médica, nem para fornecer aconselhamento médico ou de saúde. NÃO vendemos ou compartilhamos seus dados com anunciantes ou empresas de marketing.

3.2 Uso da Idade

A idade é coletada diretamente por você (não determinada automaticamente) e usada apenas para cálculos de gamificação, personalização de estatísticas e melhoria da experiência. Não usamos APIs automáticas para determinar idade.

3.3 Uso de Fotos

A permissão de câmera e galeria é usada exclusivamente para você tirar ou selecionar uma foto de perfil — funcionalidade totalmente opcional e iniciada apenas por você. Não acessamos outras fotos ou arquivos do seu dispositivo.

4. Armazenamento de Dados

4.1 Armazenamento Local

Dados de progresso pessoal são armazenados localmente no seu dispositivo (SharedPreferences), garantindo que o cronômetro funcione mesmo offline.

4.2 Armazenamento na Nuvem (Firebase)

  • Firebase Authentication: gerenciamento seguro de login
  • Cloud Firestore: mensagens do chat, perfis públicos e dados de comunidade
  • Firebase Storage: fotos de perfil
  • Firebase Cloud Messaging: notificações push

Todos os dados são transmitidos de forma criptografada (HTTPS/TLS). O Firebase possui certificações internacionais (ISO 27001, SOC 2, SOC 3). Regras de segurança impedem acesso não autorizado.

4.3 Segurança

Mensagens privadas são visíveis apenas para você e o destinatário. Você pode excluir sua conta e todos os dados associados a qualquer momento. Mantemos um sistema de moderação para manter a comunidade segura.

5. Compartilhamento de Dados

Não vendemos ou compartilhamos seus dados pessoais com terceiros para fins comerciais ou de marketing.

5.1 Visível para todos os usuários

  • Nome de usuário, foto de perfil (se adicionada), nível e conquistas
  • Mensagens enviadas no chat global
  • Status online/offline

5.2 Visível apenas para destinatários específicos

  • Mensagens privadas (apenas você e o destinatário)
  • Pedidos de ajuda SOS (visíveis para quem aceitar ajudar)

5.3 Dados que NÃO compartilhamos

Seu e-mail, sua idade, quantidade de cigarros que fumava, valor do maço, dados financeiros, tempo exato do cronômetro e estatísticas detalhadas de progresso.

5.4 Serviços de Terceiros

Utilizamos o Firebase (Google) para autenticação, armazenamento de dados da comunidade e notificações push — Política de Privacidade do Firebase · Termos de Serviço do Google.

6. Seus Direitos

Você tem o direito de acessar, corrigir e excluir seus dados, excluir mensagens enviadas, remover sua foto de perfil, desativar notificações e recusar a coleta de informações (o que pode limitar funcionalidades de comunidade). Para excluir sua conta e todos os dados associados no Firebase, entre em contato conosco.

7. Moderação da Comunidade

7.1 Regras de Conduta

São proibidos: mensagens ofensivas, discriminatórias ou inapropriadas; spam e conteúdo comercial não autorizado; compartilhamento de dados pessoais de terceiros; assédio ou intimidação.

7.2 Sistema de Moderação

Moderadores podem revisar mensagens reportadas. Após 3 avisos, o usuário pode ser suspenso temporariamente (24 horas). Violações graves podem resultar em banimento permanente. Todas as ações de moderação são registradas em logs de auditoria.

7.3 Reportar Conteúdo

Use a função de reportar mensagem no chat, ou entre em contato conosco diretamente pelo e-mail.

8. Idade Mínima

Este aplicativo é destinado a usuários com 13 anos ou mais. Se você tem menos de 13 anos, não deve usar este aplicativo.
